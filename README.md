# КЭШ — лендинг личной CRM

Одна статичная страница. Цель — перейти в приложение по кнопке «Запомнить всех».

## Запуск

```sh
pnpm install
pnpm dev       # http://localhost:4321, правки видны сразу
pnpm build     # готовый сайт в папке dist/
pnpm preview   # посмотреть собранный dist/
```

## Где что лежит

- Тексты страницы — `src/content/landing.ts`
- Цвета, шрифты, размеры текста и отступы — `src/styles/tokens.css`
- Секции страницы — `src/components/`
- Макет и спецификация — `design/`

## Ссылка на приложение

Кнопки ведут на `https://app.ekemel.ru`. Чтобы поменять адрес, добавьте в `.env` строку:

```
PUBLIC_APP_URL=https://новый-адрес
```
